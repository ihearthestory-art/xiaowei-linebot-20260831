# 課堂練習用模擬資料集

**全部是假資料**，可以隨便玩、隨便算錯。以 2026-08-30 為「今天」。

| 檔案 | 筆數 | 練什麼 |
|---|---|---|
| `01_google評論_模擬.csv` | 72 | 評論分類、情緒分析、負評回覆 |
| `02_顧客名單_模擬.csv` | 140 | 顧客分群、找出沉睡客 |
| `03_訂單明細_模擬.csv` | 2,913 | 哪道菜賺錢、誰是大客戶、什麼時段空 |
| `04_群發成效_模擬.csv` | 12 | 算開封率、比較分眾與全體群發 |

## 怎麼下載

在 GitHub 上點檔名 → 右上角「Download raw file」。
或直接把整個資料夾的網址貼給 AI，請它讀。

## 怎麼用

把 CSV 檔案**直接上傳**給 ChatGPT 或 Gemini，然後問它問題。例如：

```
這是我店裡的顧客名單。請幫我：
1. 分成新客、熟客、沉睡客三群，各幾人
2. 列出最該挽回的 20 位客人，說明為什麼是他們
3. 給我一則 60 字內的喚回訊息，可以直接貼進 LINE 群發
```

`00_講師解答.md` 是給講師看的，裡面寫了資料裡埋了哪些結論。

# 小微示範小館 LINE 營運助理

## 目標

先讓客人完成查詢、留下訂位需求、轉真人與回饋；AI 只協助理解問法與整理，不取代店家確認。

## 第一版

- 六格入口：菜單、營業時間、怎麼去、訂位、真人客服、給建議
- FAQ 與過敏原安全回覆
- 三段式訂位需求收集，資料狀態一律 `pending`
- 真人客服與客訴回饋建立案件
- SQLite 留下訂位／交接／回饋紀錄

## 第二版 AI

- 規則未命中時，使用受控知識庫回答；無資料時轉真人
- 對話與回饋摘要、緊急度標記
- 老闆確認後才產生回訪或活動文案

## 不做

- 不自動確認訂位、不自行承諾過敏原安全
- 不自動群發促銷、不把憑證寫進 Git 或訊息
- 沒有 POS／訂位系統資料前，不做庫存或桌位即時查詢
